- **วิธีง่าย:** ทำฝั่งหนึ่งเสร็จ → แท็บ "ฉัน" → ออกจากระบบ → เข้าอีกบัญชี → ทำต่อ
- **ถ้าอยากเห็นข้อความเด้งสด:** เปิด MuMu อีก instance (Multi-instance) แล้วเข้าคนละบัญชี — ต้อง `adb reverse` ให้ instance ที่สองด้วย

| # | ทำ | ควรเห็น | ☐ | TC |
|---|---|---|---|---|
| 9.1 | ฉัน → "ความเป็นส่วนตัวและข้อมูลของฉัน" | ประกาศครบ (ข้อมูลที่เก็บ ระยะเวลา สิทธิ) 📸 | ☐ | — |
