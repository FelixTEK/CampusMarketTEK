# บัญชีทดสอบ (seed) — ล็อกอินใครได้บ้าง

ใช้เฉพาะตอนพัฒนา/สาธิต ก่อนส่งงานให้ลบบัญชีเหล่านี้ออก

## 1) นักศึกษา สจล. (SSO จำลอง — ต้องตั้ง `KMITL_DUMMY=true` ใน `backend/.env`)

กดปุ่ม "เข้าสู่ระบบด้วยบัญชี KMITL" ในแอป แล้วเลือกการ์ดนักศึกษาในหน้าล็อกอินจำลอง (ไม่มีรหัสผ่าน)
ช่องอีเมลสถาบันกรอกเองหรือเว้นว่างได้ ถ้ากรอกต้องลงท้าย `@kmitl.ac.th`

| รหัสนักศึกษา | ชื่อ | คณะ / หลักสูตร | สถานภาพ | ผลล็อกอิน |
|---|---|---|---|---|
| 69010012 | นางสาวสมหญิง ใจดี | วิศวกรรมศาสตร์ / วิศวกรรมคอมพิวเตอร์ | เรียน | ผ่าน |
| 67050514 | นายธีรภัทร ศรีสุข | วิทยาศาสตร์ / วิทยาการคอมพิวเตอร์ | เรียนเกินหลักสูตร | ผ่าน |
| 56070069 | นาย John Doe | วิศวกรรมศาสตร์ / วิศวกรรมคอมพิวเตอร์ (level 1) | จบ | **ไม่ผ่าน** (ใช้ทดสอบกรณีถูกปฏิเสธ ไม่สร้างบัญชี) |

- ผู้ที่ผ่านจะได้ชื่อที่แสดง = ชื่อ + นามสกุลไทย และคณะตามข้อมูล (แก้เองได้ในแท็บ "ฉัน")
- ข้อมูลอยู่ใน `backend/src/kmitl/dummy.ts` · ดู JSON ตัวอย่างได้ที่
  `GET /dummy/student-catalog/v1/students[/{id}]` (ต้องมี header `apikey` ค่าอะไรก็ได้)
- สถานภาพที่ผ่าน: เรียน · เปลี่ยนหลักสูตร · รออนุมัติสำเร็จการศึกษา · โอนย้ายข้ามคณะ · ครบหลักสูตร (ค้างชำระ) · เรียนเกินหลักสูตร

## 2) บุคคลภายนอก (ล็อกอินด้วยอีเมล + รหัสผ่าน)

สร้างโดย `bun scripts/seed-demo.ts` (รหัสผ่านทุกบัญชีด้านล่างคือ `TestPass-12345`)

| อีเมล | ชื่อที่แสดง | บทบาท |
|---|---|---|
| `seller2@example.test` | ต้น | ผู้ขาย (เจ้าของประกาศ demo) |
| `buyer1@example.test` | มิ้นท์ | ผู้ซื้อ |

## 3) ผู้ดูแลระบบ

ไม่มีหน้าสมัครผู้ดูแลในแอปโดยตั้งใจ สร้างหรือรีเซ็ตรหัสผ่านได้ด้วย

```bash
cd backend
bun scripts/dev-admin.ts admin@campusmarket.test "รหัสผ่านอย่างน้อย 8 ตัว"
```

แล้วล็อกอินในแอปด้วยอีเมล + รหัสผ่านที่ตั้ง (ฟอร์ม "บุคคลภายนอก")

## หมายเหตุ

- อีเมล `@kmitl.ac.th` สมัครแบบบุคคลภายนอกไม่ได้ ต้องเข้าทางปุ่ม KMITL
- บัญชี สจล. ล็อกอินด้วยรหัสผ่านไม่ได้
