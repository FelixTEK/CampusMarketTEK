# บัญชีทดสอบ (seed) — ล็อกอินใครได้บ้าง

ใช้เฉพาะตอนพัฒนา/สาธิต ก่อนส่งงานให้ลบบัญชีเหล่านี้ออก

## 1) นักศึกษา สจล. (SSO จำลอง — ต้องตั้ง `KMITL_DUMMY=true` ใน `backend/.env`)

กดปุ่ม "เข้าสู่ระบบด้วยบัญชี KMITL" ในแอป แล้วเลือกการ์ดนักศึกษาในหน้าล็อกอินจำลอง (ไม่มีรหัสผ่าน) · มีการ์ด 18 ใบ: 3 ใบแรกในตารางนี้ + นักศึกษาสาธิตอีก 15 คนในข้อ 2
ช่องอีเมลสถาบันกรอกเองหรือเว้นว่างได้ ถ้ากรอกต้องลงท้าย `@kmitl.ac.th`

| รหัสนักศึกษา | ชื่อ | คณะ / หลักสูตร | สถานภาพ | ผลล็อกอิน |
|---|---|---|---|---|
| 69010012 | นางสาวสมหญิง ใจดี | วิศวกรรมศาสตร์ / วิศวกรรมคอมพิวเตอร์ | เรียน | ผ่าน |
| 67050514 | นายธีรภัทร ศรีสุข | วิทยาศาสตร์ / วิทยาการคอมพิวเตอร์ | เรียนเกินหลักสูตร | ผ่าน |
| 56070069 | นาย John Doe | วิศวกรรมศาสตร์ / วิศวกรรมคอมพิวเตอร์ (level 1) | จบ | **ไม่ผ่าน** (ใช้ทดสอบกรณีถูกปฏิเสธ ไม่สร้างบัญชี) |

- ผู้ที่ผ่านจะได้ชื่อที่แสดง = ชื่อ + นามสกุลไทย และคณะตามข้อมูล (แก้เองได้ในแท็บ "ฉัน")
- ข้อมูลอยู่ใน `backend/src/kmitl/dummy.ts` · ดู JSON ตัวอย่างได้ที่
  `GET /dummy/student-catalog/v1/students[/{id}]` (ต้องมี header `apikey` ค่าอะไรก็ได้)
- สถานภาพที่ผ่าน: เรียน · เปลี่ยนหลักสูตร · รออนุมัติสำเร็จการศึกษา · โอนย้ายข้ามคณะ · ครบหลักสูตร (ค้างชำระ) · เรียนเกินหลักสูตร

## 2) ข้อมูลสาธิต: ผู้ขาย 20 คน + ผู้ซื้อ 10 คน (สร้างด้วย `bun scripts/seed-demo.ts`)

```bash
cd backend && bun scripts/seed-demo.ts            # ล้างข้อมูลสาธิตเดิมแล้วสร้างใหม่ (ได้ชุดเดิมทุกครั้ง)
cd backend && bun scripts/seed-demo.ts --remove   # ล้างอย่างเดียว
```

- **ผู้ขาย 20 คน** (สุ่มหมวด): หนังสือเรียน 8 คน · อุปกรณ์คอมพิวเตอร์ 8 คน · เครื่องเขียน 4 คน รวมประกาศ 64 รายการ สภาพสินค้า 5 ระดับ (ใหม่ยังไม่แกะ → มีตำหนิชัดเจน) ราคาปรับตามสภาพ
- **ผู้ซื้อ 10 คน** ไม่มีประกาศ
- **ทั้งผู้ขายและผู้ซื้อเป็นสมาชิก สจล. ครึ่งหนึ่ง และบุคคลภายนอกอีกครึ่งหนึ่ง** (ผู้ขาย 10/10 · ผู้ซื้อ 5/5)
- ไม่ต้องเปิด backend ตอนรันสคริปต์ แต่ต้องมีฐานข้อมูล · ล้างเฉพาะบัญชีที่อีเมล `*@example.test` หรือ kmitl_sub ขึ้นต้น `seed-kmitl-`
- **บุคคลภายนอก** ล็อกอินด้วยอีเมล + รหัสผ่าน `TestPass-12345` (ทุกบัญชี) ที่ช่อง "บุคคลภายนอก"
- **สมาชิก สจล. 15 คนในชุดนี้ล็อกอินได้ผ่าน SSO จำลอง** (ต้องตั้ง `KMITL_DUMMY=true`): กดปุ่ม "เข้าสู่ระบบด้วยบัญชี KMITL" แล้วเลือกคนนั้นในหน้าล็อกอินจำลอง (ทุกคนสถานภาพ "เรียน") จะเข้าบัญชีเดิมพร้อมประกาศ · ข้อมูลของพวกเขาอยู่ใน `DEMO_STUDENTS` ที่ `backend/src/kmitl/dummy.ts` ชุดเดียวกับที่ seed ใช้ · อีเมลรูปแบบ `รหัสนักศึกษา@kmitl.ac.th`

## 3) ผู้ดูแลระบบ

ไม่มีหน้าสมัครผู้ดูแลในแอปโดยตั้งใจ สร้างหรือรีเซ็ตรหัสผ่านได้ด้วย

```bash
cd backend
bun scripts/dev-admin.ts admin@campusmarket.test "รหัสผ่านอย่างน้อย 8 ตัว"
```

แล้วล็อกอินในแอปด้วยอีเมล + รหัสผ่านที่ตั้ง (ฟอร์ม "บุคคลภายนอก")

## หมายเหตุ

- อีเมล `@kmitl.ac.th` สมัครแบบบุคคลภายนอกไม่ได้ ต้องเข้าทางปุ่ม KMITL
- บัญชี สจล. ล็อกอินด้วยรหัสผ่านไม่ได้
