## 5. ที่ยังไม่ได้ทดสอบ (ต้องรู้)

| เรื่อง | เหตุผล / ผลกระทบ |
|---|---|
| ผู้ใช้หลายเครื่องพร้อมกันจริง | ตัดออกตามขอบเขต proof of concept · ฝั่งผู้ขายในการทดสอบบนเครื่องใช้ API แทนเครื่องที่สอง · การแข่งกันตกลงขายทดสอบที่ระดับ API (TC-30, TC-31) |
